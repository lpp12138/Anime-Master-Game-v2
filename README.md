# 动漫高手·一眼顶针

多人实时动画截图猜番小游戏。房主创建房间并选择本局出题人，出题人准备截图题库，房主开始游戏，玩家根据逐块揭露的图片猜动画名，最后进入排行榜结算。

生产部署推荐给 Cloudflare Pages 绑定自定义域名，并把 Worker 配到同源 `/api/*` 路由。

## 怎么玩

### 创建或加入房间

1. 打开网站。
2. 输入昵称。
3. 创建公开或私人房间、从公开房间大厅选择加入，或输入 6 位房间号加入朋友的房间。公开房间名称可以留空，此时使用“昵称的房间”。
4. 房主在大厅中选择一名玩家作为本局出题人。

### 准备题库

出题人可以选择一种方式准备题库：

- 上传本地图片或整个文件夹。
- 粘贴图片 URL 文本。
- 导入 JSONL 文件。
- 选择社区题库。

题库准备完成后，房主会看到“开始游戏”按钮变为可用，并可选择使用全部题目或随机抽取较少题数。抽取由服务端无重复完成并固定本局顺序，刷新、重连或重试开局不会重新抽题。房主点击后，本局游戏正式开始。

### 游戏过程

- 每张图片会被切成 45 块，逐轮揭露。
- 出题人能看到原图和网格，选择本轮要揭露的块。
- 玩家根据已揭露部分提交答案。
- 出题人打开判分面板，勾选答对的玩家。
- 猜题界面积分榜旁显示“出题人”与“裁判”两个标签：“出题人”是当前图片在社区图库中的上传者昵称（非社区题库或未知历史投稿时回退为裁判昵称），“裁判”是本局出题人玩家；两者为同一人时只显示“出题人”。
- 越早答对，得分越高。
- 每道题可单独标记为 R18（成人内容）作为内容提示，不自动遮罩、隐藏或删除，也不影响判定、计分或结算；R18 角标保留在上传页、题库预览和管理页，游戏进行画面与复盘弹窗不显示。
- 题库选择完成后，房主可在房间游戏设置中开关“包含 R18 题目”（默认关闭）：关闭时服务端准备题库和开局抽题都会排除 R18 题目，可用题数重新计算（每局仍最多 30 题）；若关闭后没有可用题目（如默认关闭时选了全 R18 题库），题库仍会成功记录，但会给出提示并禁止开始，房主打开开关后重算即可开始。
- 题库全部完成后进入排行榜。

### 出题工具

首页和房间页都有“我要出题”入口。弹窗里可以打开动画截图工具，快速整理截图，再回到游戏中上传或导入题库。

### 密钥上传服务器题库

首页“密钥上传截图”按钮会直接进入独立上传页，允许获授权的上传者一次提交 1–30 张截图并保存为公开社区题库。题库标题栏默认不选中任何题库，也不进入新建模式：必须由用户从下拉框明确选择要追加的现有题库（按题库 ID 追加，管理员已新增、删除或调序的公开社区题库也可继续接收新图片），或选择“新建题库”并自行填写标题（新建标题默认留空，无默认名称）；未明确选择时不能提交。整套题库不再受累计 30 题限制，可跨多次投稿持续追加；单次投稿与每局游戏仍最多使用 30 题。密钥通过受保护列表接口验证成功后即可选择题库，刷新列表不会覆盖用户的选择。页面支持文件选择、多图拖放、Ctrl/Cmd+V 粘贴剪贴板截图，也可上传或粘贴动画截图工具的 `.jsonl` / `.json` 题单，或每行粘贴一个 FanCaps/Bangumi 截图直链。远端图片只通过受密钥保护且限定来源域名的 Worker 接口下载，再由浏览器压缩并上传，不会把密钥发送给图片源站。

选择或导入图片后会以自适应缩略图网格展示；点击某张截图即可在侧边编辑区填写正确答案和标签，完成后答案、Bangumi 作品及角色会叠加显示在对应缩略图上。每张截图可以单独勾选“标记为 R18（成人内容）”，缩略图左上角会显示红色 R18 角标，与答案/Bangumi 标签互不影响。正确答案输入框同时作为 Bangumi 作品搜索框，可切换“动画”“游戏”或“全部”，其下可按角色名从所选作品的官方角色列表搜索添加画面中实际出现的角色。Worker 通过官方 Bangumi v0 API 获取规范 ID、类型和名称，并使用服务端 Cache API 缓存搜索 12 小时、作品详情 30 天、整份角色列表 7 天；选择角色直接复用列表结果，不再逐角色请求详情。finalize 会重新按 ID 规范化作品名称/类型并校验角色确属该作品，避免信任客户端自报标签，同时避免浏览器直连和 N+1 请求 Bangumi。图片索引在 D1 中按题保存答案、作品与角色标签及 R18 标记，作品 ID 使用普通索引，最多 8 个角色以有界 JSON 保存。每次社区截图上传还会使用单段 R2 对象 ETag 对应的 MD5 做全局精确文件去重；若相同文件已在图片索引中，页面会定位当前截图并提示“题库已有”及现有题库/题号，服务端不会只依赖文件名或浏览器判断。

密钥只通过 `x-community-upload-key` 请求头提交并由 Worker 的 `COMMUNITY_UPLOAD_SECRET` 校验，不会进入前端构建。带 Bangumi 作品标签的图片还会同步保存官方属性标签（异世界、恋爱等用户标签，最多 20 条）与首播年份，供题库筛选使用。横图限制为 1920×1080，竖图限制为 1080×1920；超出时浏览器自动等比压缩，Worker 仍会校验真实图片格式和最终尺寸后再保存。finalize 请求体限制为 512 KiB，并使用与投稿内容指纹绑定的客户端稳定投稿 ID 幂等重试；R18 标记属于投稿内容，改变它会生成新指纹并拒绝旧 ID 重放。新建时题库、逐图索引和投稿记录原子写入，追加时 manifest、图片计数、逐图索引和投稿记录通过带修订号比较的 D1 batch 原子更新；manifest 与 `question_image_index` 均持久化每题 `is_r18`，旧数据默认 false。`question_image_index.image_md5` 的 partial unique index 会在 finalize 原子提交时再次阻止同批重复和并发重复；MD5 只用于精确字节去重，不作为安全签名，也不会通过公开题库 API 返回。`.jsonl` / `.json` 题单可选用 `is_r18` 或 `isR18` 布尔字段（缺省 false，字符串等错误类型会被拒绝），导入后逐题保留并可编辑；“复制上一张标签”同时复制 R18 标记。受密钥保护的 `/api/community-image-index` 可按 Bangumi 作品及可选角色查询最多 50 张公开题库图片，只返回图片标识、规范标签与 R18 标记，不返回答案。

### 受保护题库管理

获授权的管理员可从截图投稿页进入 `/question-set-admin`。管理密钥只保留在当前页面内存，并复用 `x-community-upload-key` 鉴权；列表支持按标题、题库 ID、上传者、公开状态和来源检索，详情页才会显示正确答案、Bangumi 标签及存储一致性报告。管理员可修改标题、说明和公开状态，也可对每道题单独查询、新增、编辑答案/标签/R18 标记、拖放或粘贴替换截图、上移/下移及删除；旧题库题目默认非 R18，管理页缩略图对 R18 题目显示角标。每次写入都要求最新 `updatedAt`，并在同一 D1 batch 中更新 manifest/legacy 题目与图片索引；单题修改仍受活动游戏、已准备房间、损坏存储和最后一题保护。题库逐题新增不再受 30 题上限约束（每次仍只新增 1 题），但每局游戏仍最多使用 30 题。

新增、删除或调序会把题库标记为“结构已人工编辑”，并解除仅凭同标题自动命中的绑定；该题库仍会出现在截图上传页，可按题库 ID 明确选择并继续追加。答案、标签或截图内容编辑不会改变题目顺序。被替换或删除的旧图片只会在 D1 成功后做完整引用扫描，并仅删除本站前缀且不再共享的 R2 对象。永久删除整个题库除管理密钥外，还要求单独配置的删除密钥（`QUESTION_SET_DELETE_SECRET`，通过 `x-question-set-delete-key` 请求头提交，仅用于整库删除）；页面会再次要求输入完整标题并提交题库 ID 与版本。有房间正准备该题库时，删除会在同一 D1 batch 中先把这些房间原子退回大厅并取消准备（成功响应返回释放的房间数），活动游戏仍被拒绝。历史结算归档是自包含快照，会继续保留。公开题库列表和图片索引仍不返回答案。

## 功能

- 多人房间和实时同步。
- 可手动刷新的公开房间大厅，展示状态、模式、人数和已准备题目的来源。
- 房主选择出题人。
- 本局可使用全部题目，或由服务端随机无重复抽取指定题数并持久化顺序。
- 上传图片、URL / JSONL 导入、社区题库选择。
- 独立密钥上传页：文件选择、多图拖放、剪贴板截图粘贴、受限直链或 JSON/JSONL（文件/粘贴）导入、同标题追加、自适应截图网格、点击逐图编辑、动画/游戏 Bangumi 搜索、角色搜索与缩略图标签叠加，超出 1080p 自动压缩。
- 受保护题库管理页：检索分页、答案与标签检查、逐题增删改查/换图/调序、元数据与公开状态并发安全更新，以及引用感知的 D1/R2 安全清理。
- 45 块图片揭露，支持横屏和竖屏截图。
- 倒计时答题。
- 出题人判分。
- 排行榜结算。
- 题库发布到社区、搜索、预览和评分。
- 刷新后恢复当前房间和游戏状态。

## 技术栈

- Vite static build for Cloudflare Pages
- React 18
- TypeScript
- Tailwind CSS
- Cloudflare Pages
- Cloudflare Workers + Durable Objects
- Cloudflare D1
- Cloudflare R2 object storage
